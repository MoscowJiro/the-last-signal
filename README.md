# THE LAST SIGNAL｜最后的信号

> **Original Sci-Fi Visual Development & Cinematic Concept Project**

《THE LAST SIGNAL》是一项个人原创的科幻视觉开发项目（Self-Initiated Visual Development Project）。

项目围绕一座位于北大西洋、废弃多年的海洋观测站 **NAOS-06** 展开，从 Narrative Concept 出发，逐步完成 Worldbuilding、Art Direction、Environment Design、Character Direction、Prop Design 与 Cinematic Keyframes，并尝试建立一套具有连续性和生产逻辑的 AI-assisted Visual Development Workflow。

本项目的重点并非生成单张独立的科幻图像，而是探索如何利用生成式工具完成一个具有统一世界观、视觉语言、空间逻辑与叙事节奏的完整 Visual Development Case Study。

---

## PROJECT OVERVIEW｜项目概述

**2041年，一座沉寂17年的北大西洋海洋观测站重新开始发送信号。**

三人调查小组被派往已经废弃的 **NAOS-06**。

进入设施后，他们发现部分系统仍然保持供电，而位于最深层的 Acoustic Monitoring System 正在接收一个与2007年最后记录完全一致的低频信号。

问题在于：

**2007年的那次信号，在系统计划发送它之前就已经被接收。**

> *The original signal was received before it was transmitted.*

## VISUAL DIRECTION｜视觉方向

项目建立在三种核心视觉语言之上：

**Cold Atlantic Realism**  
寒冷、潮湿、低饱和度的北大西洋环境，以自然天气和真实海洋工程尺度建立孤立感。

**Industrial Brutalism**  
Reinforced Concrete、Painted Marine Steel、裸露管线、Cable Systems 与大型工业结构构成 NAOS-06 的主要建筑语言。

**Analog Technology**  
CRT、Reel-to-Reel Recorder、Analog Meter、Hydrophone System 与旧式 Acoustic Monitoring Equipment 构成项目的技术基础。

整个项目遵循一个核心原则：

> **The world stays believable. The information does not.**  
> 世界始终可信，真正变得不可能的是其中的信息。

因此项目刻意避免 Neon、Hologram、Cyberpunk UI、未来主义设备以及直接可见的超自然实体。

## NAOS-06｜空间设计

NAOS-06 表面是一座建于约 **1998–2004** 年间的 Offshore Oceanographic Research Station。

但调查过程中发现，官方图纸只记录了设施的一部分。

在约 **−52 m** 以下存在一条未被记录的 Vertical Shaft，并继续向海平面以下延伸超过100米，最终抵达：

**B12 / Approx. −176 m**

最深处并不存在巨大的未来设施，而是一间约供一名操作员工作的 Listening Room。

其建筑方式和 Analog Equipment 显示，这部分基础设施可能来自 **1970s–1980s**，明显早于上方的 NAOS-06。

空间叙事遵循：

**Normal → Unusual → Impossible → Intimate**

## THE SIGNAL｜信号

B12 的核心异常是一组 Ultra-Low-Frequency Acoustic Pattern：

**Center Frequency**  
`17.4 Hz`

**Duration**  
`00:41.8`

2007年的档案显示：

**Received**  
`14 OCT 2007 — 23:17:42 UTC`

**Scheduled Transmission**  
`15 OCT 2007 — 06:00:00 UTC`

两者相差：

**06:42:18**

也就是说：

> **Effect appeared before cause.**

而 Received Recording 中还存在一个 Scheduled Output 中没有出现的微弱 Terminal Pulse。

因此它并不是一个完全相同的“回声”。

## ENVIRONMENTAL STORYTELLING｜环境叙事

项目没有通过怪物、爆炸或直接的 Supernatural Visuals 建立悬念，而是让异常逐渐出现在普通环境和技术系统中：

**ARRIVAL**  
一座看似正常废弃的海洋研究站。

**THE CORRIDOR**  
废弃17年的设施仍然存在大面积照明。

**SIGNAL ROOM**  
几乎全部停机的设备中，只有一个 Terminal 仍然工作。

**THE SHAFT**  
官方建筑图纸中不存在的百米级地下结构。

**B12**  
巨大基础设施的尽头，却只是一间普通 Listening Room。

**DEEP-OCEAN ARRAY**  
信号在不同 Acoustic Sensors 中几乎同时出现，无法通过 Arrival-Time Difference 确定明确传播方向。

**THE SEARCH**  
Deep-Ocean Survey 没有发现可以识别的 Physical Source。

**THE LAST SIGNAL**  
Active Transmission 被关闭之后，Recorder 再次开始工作。

异常始终存在，但从未被直接视觉化。

## MARA VENN｜角色方向

**Mara Venn**  
31岁 / Signal Analyst

Mara 被设计为 Civilian Scientific Field Researcher，而不是传统科幻作品中的 Action Hero。

她没有 Weapon、Tactical Armor 或 Futuristic Equipment，仅使用符合 Offshore Investigation 场景的 Waterproof Workwear、Radio、Headlamp 与基础 Field Equipment。

角色设计遵循：

**Practical / Civilian / Observational**

> **She is there to observe, not to conquer.**

在大量环境镜头中，Mara 同时承担 Human Scale 的作用，通过人物与建筑、深井和海洋基础设施之间的比例关系建立空间尺度。

## VISUAL DEVELOPMENT WORKFLOW｜视觉开发流程

项目采用从 Narrative 到 Final Master 的结构化 Visual Development Workflow：

`CONCEPT`

↓

`WORLD BUILDING`

↓

`DESIGN SYSTEM`

↓

`VISUAL EXPLORATION`

↓

`SELECTION`

↓

`REFINEMENT`

↓

`CINEMATIC KEYFRAMES`

↓

`FINAL MASTER`

生成式工具在项目中主要作为 **Visual Production Tool** 使用，而不是替代设计决策。

每轮 Visual Exploration 都需要根据已经建立的 Architecture、Material Language、Lighting、Scale、Character Continuity 与 Narrative Function 进行筛选。

视觉效果突出但破坏世界观一致性的方案不会进入 Final Master。
